# RubUP Helper (Telegram Userbot + TikTok Generator + Accounting)

Цей проєкт призначений для автоматизації роботи з ботами RubUP та TikTok з розгортанням на безкоштовному **Render Web Service** (24/7).

---

## 🌟 Можливості:
1. ⏰ **Автозбір картинок за розкладом**:
   - О **00:00, 08:00, 16:00** (за київським часом) заходить у `@rubupcomment_bot`.
   - Тисне «Сгенерировать картинки» + 4 рази «Ещё картинка».
   - Пересилає **тільки 5 картинок** вам у «Збережене» (Saved Messages).
2. 💬 **Генератор анти-спам коментарів для TikTok**:
   - Від 1 до 30 коментарів за командою `/gen <кількість>` (наприклад `/gen 15`).
   - Усі тексти з обов'язковими словами (`RubUP`, `рубап`, `в рубапе`, `рубапом`, `@RubUP`), складені випадковим чином, щоб TikTok їх не банив.
3. 📊 **Автоматична та ручна статистика заробітку**:
   - Автоматично перехоплює виплати від `@rubup` та записує кількість коментарів і карбованці в SQLite.
   - Команди: `/zvit7` (за 7 днів), `/zvit30` (за 30 днів), `/zvit_all` (за весь час).
   - Ручний запис: `/zvit 20 60` (20 коментарів, 60 рублів).
4. 🚀 **Кнопка ручного збору**:
   - `/collect` — якщо хочете зібрати 5 картинок прямо зараз.

---

## 🚀 Інструкція із запуску

### Крок 1: Отримайте API_ID та API_HASH
1. Перейдіть на [my.telegram.org](https://my.telegram.org) і введіть свій номер телефону від Telegram.
2. Перейдіть у розділ **API development tools**.
3. Створіть новий додаток (назвіть як завгодно, наприклад `RubUpApp`).
4. Скопіюйте **`api_id`** та **`api_hash`**.

### Крок 2: Отримайте рядок сесії (STRING_SESSION)
1. На комп'ютері в папці проєкту встановіть залежності:
   ```bash
   pip install telethon
   ```
2. Запустіть скрипт:
   ```bash
   python generate_session.py
   ```
3. Введіть `api_id`, `api_hash`, номер телефону та код із Telegram.
4. Скрипт виведе довгий рядок `STRING_SESSION`. **Збережіть його**.

---

### Крок 3: Завантаження на GitHub
1. Створіть новий приватний репозиторій на [GitHub](https://github.com/new).
2. Завантажте туди всі файли з цієї папки:
   - `app.py`
   - `comments_generator.py`
   - `database.py`
   - `requirements.txt`

---

### Крок 4: Розгортання на Render.com (Web Service)
1. Зареєструйтесь / увійдіть на [Render.com](https://render.com).
2. Натисніть **New +** -> **Web Service**.
3. Підключіть свій GitHub-репозиторій.
4. Налаштування:
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`
   - **Instance Type**: `Free`
5. Відкрийте розділ **Environment Variables** (Змінні оточення) та додайте:
   - `API_ID` — ваш api_id (число)
   - `API_HASH` — ваш api_hash
   - `STRING_SESSION` — отриманий довгий рядок сесії
   - `TZ` — `Europe/Kyiv`
6. Натисніть **Deploy Web Service**.

Готово! Тепер сервіс працює в хмарі 24/7. Керувати ним можна прямо з ваших **Saved Messages** у Telegram.
